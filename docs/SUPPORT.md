# Drift support

For help, a bug report, or a feature request,
[open an issue](https://github.com/cjbest/drift/issues/new) on the Drift project.
Include your device, operating system, Drift version, and what happened.
Issues are public; please keep private notes and personal information out of
your report. You can also send feedback through TestFlight when using a beta.

## Getting started

See the [README](../README.md) for installation options.

On iPhone or iPad, choose a folder for your notes when Drift first opens. You
can choose an existing folder or create one in the Files picker. Tap **+** to
write a note. To change folders later, use **Notebook Options → Change Folder**.

On a new Mac installation, just start writing. Drift keeps your notes in
**Documents → Drift** and opens a short introduction the first time. Existing
installations keep their current folder.

Use **File → Choose Notebook Folder…** to choose or create another folder, or
**File → Show Notebook in Finder** to see the current files. Changing folders
saves your open notes and reopens Drift; it leaves existing notes in their
original folder. For setup details, see the
[installation guide](INSTALL.md#notebook-location).

## Using the same notes on both devices

Both apps must use the same actual folder in iCloud Drive. Drift itself does
not operate a sync service. Before troubleshooting sync, check that the notes
are available in that folder in Finder or Files and that iCloud has finished
downloading them.

## Saving and recovery

Notes save automatically as Markdown files. If a save fails, keep the app and
its local data in place while resolving the error; recovery data may contain
your latest writing. Back up your notebook before moving or reorganizing it.

On iPhone or iPad, use **Notebook Options → Undo Last Delete** to restore a
deleted note. If another app changes the same note while you are editing,
Drift preserves conflicting writing as a separate recovered copy.

See the [privacy policy](PRIVACY.md) for how Drift handles your data.
