# Drift 0.2.1 for Mac

A few improvements to finding notes and working with checklists.

- **Check for Updates…** in the Drift menu opens the Drift website, where you
  can download the latest release.
- Dates in the note list now reflect when you last opened or edited each note,
  matching the order of the list.
- **⌘Return** turns a plain line into an unchecked checklist item. On an
  existing checklist item, it checks or unchecks it, including numbered lists.

## Install or update

1. Download **Drift-0.2.1-macOS-AppleSilicon.dmg**.
2. Quit Drift if it is running, then open the download and drag **Drift** into
   **Applications**, replacing the previous app if prompted.
3. Open Drift. Existing notes and the selected notebook folder stay in place.

**Apple Silicon (M1 or newer) · macOS 14 or later.** No developer account or
Xcode needed. A new installation starts in **Documents → Drift**.

Updates use this download-and-replace flow. The menu link does not compare
versions or install updates automatically.

For help or feedback, [open an issue](https://github.com/cjbest/drift/issues/new).
Please keep private notes out of public bug reports.
