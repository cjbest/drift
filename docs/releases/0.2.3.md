# Drift 0.2.3 for Mac

More reliable text selection and copying, especially around links and notes
updated from another device.

- Drag from a compact link to select text, including scrolling past the visible
  page while continuing the selection.
- Keep an active selection when another device edits elsewhere in the note.
- Preserve normal selection gestures around checklist markers and keep copying
  and undo reliable after text is replaced.
- Start a new note immediately, so typing or pasting while the previous note
  saves lands on the new page.

## Install or update

1. Download **Drift-0.2.3-macOS-AppleSilicon.dmg**.
2. Quit Drift, open the download, and drag **Drift** into **Applications**,
   replacing the previous app if prompted.
3. Open Drift. Existing notes and the selected notebook folder stay in place.

**Apple Silicon (M1 or newer) · macOS 14 or later.** No developer account or
Xcode needed. A new installation starts in **Documents → Drift**.

Updates use this download-and-replace flow. **Drift → Check for Updates…** opens
the download website; it does not install updates automatically.

For help or feedback, [open an issue](https://github.com/cjbest/drift/issues/new).
Please keep private notes out of public bug reports.

## Validation and coverage

The Apple Silicon download is signed with the owner's Developer ID, notarized
by Apple, and stapled. The installer and its contained app passed Gatekeeper.
Release checks passed 200 Chromium/WebKit tests, 39 native Rust tests, and
9 editor/session tests. Native checks confirmed immediate New Note typing and
paste, separate files during rapid creation, whole-note copying after scrolling,
and saving when a new window closes immediately.

Fresh-account/second-Mac installation, macOS 14 specifically, and physical
iCloud synchronization/offline/concurrent-edit scenarios were unavailable in
this release run. The macOS 14 minimum is a compatibility declaration, not a
claim that this release was exercised on that OS. The final native Quit/relaunch
recheck was unavailable because the automation timed out; automated close/quit
failure recovery and native window-close saving passed.
