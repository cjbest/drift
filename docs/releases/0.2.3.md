# Drift 0.2.3 for Mac

More reliable text selection and copying, especially around links and notes
updated from another device.

- Drag from a compact link to select text, including scrolling past the visible
  page while continuing the selection.
- Keep an active selection when an unchanged note receives edits elsewhere.
- Preserve normal selection gestures around checklist markers and keep copying
  and undo reliable after text is replaced.

## Install or update

1. Download **Drift-0.2.3-macOS-AppleSilicon.dmg**.
2. Quit Drift, open the download, and drag **Drift** into **Applications**,
   replacing the previous app if prompted.
3. Open Drift. Existing notes and the selected notebook folder stay in place.

**Apple Silicon (M1 or newer) · macOS 14 or later.** No developer account or
Xcode needed. A new installation starts in **Documents → Drift**.

Updates use this download-and-replace flow. **Drift → Check for Updates…** opens
the download website; it does not install updates automatically.

For help or feedback, [open an issue](https://github.com/cjbest/drift/issues/new).
Please keep private notes out of public bug reports.
