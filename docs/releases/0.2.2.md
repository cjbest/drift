# Drift 0.2.2 for Mac

Pinned notes now stay pinned when moving between iPhone and Mac.

- Notes pinned on iPhone appear first in the Mac note list, with a small pin
  beside pinned notes only.
- Editing or renaming a pinned note on Mac preserves its pin, including when
  another note already has the same title.
- Pins travel with the Markdown files in your shared folder. Choose the same
  iCloud Drive folder on iPhone and Mac to keep notes and pins together.

## Install or update

1. Download **Drift-0.2.2-macOS-AppleSilicon.dmg**.
2. Quit Drift if it is running, then open the download and drag **Drift** into
   **Applications**, replacing the previous app if prompted.
3. Open Drift. Existing notes and the selected notebook folder stay in place.

**Apple Silicon (M1 or newer) · macOS 14 or later.** No developer account or
Xcode needed. A new installation starts in **Documents → Drift**.

Updates use this download-and-replace flow. **Drift → Check for Updates…** opens
the download website; it does not install updates automatically.

For help or feedback, [open an issue](https://github.com/cjbest/drift/issues/new).
Please keep private notes out of public bug reports.
